PUBLICAÇÃO NO GITHUB PAGES

1. Extraia este ZIP.
2. Envie o conteúdo da pasta processos_renault_github_pages/ para a raiz do diretório publicado no repositório.
3. Confira que index.html, assets/ e data/ estejam no mesmo nível.
4. Em Settings > Pages, configure a branch e a pasta da publicação.
5. Abra https://usuario.github.io/nome-do-repositorio/ após a publicação.
6. Não abra index.html por duplo clique (file://); esta versão requer HTTP.
7. Para uso local sem servidor utilize HTML completo (offline).
8. ATENÇÃO: se os chassis foram incluídos, VINs ficam acessíveis em arquivos estáticos a todos com acesso ao site.
